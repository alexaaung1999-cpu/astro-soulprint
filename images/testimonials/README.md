# Testimonial screenshots

Drop your screenshots here and name them:

    testimonial-1.jpg
    testimonial-2.jpg
    ...
    testimonial-6.jpg

Until a file exists, the page shows a soft placeholder box. Use .jpg, or change
the `src` in `index.html` if you prefer .png / .webp. Keep each image under
about 300 KB so the page loads fast on phones. Blur or crop out names if you do
not have permission to show them.
